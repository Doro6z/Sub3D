# Sub3D Proto 03 - Brief Outsourcing 3D FR

Date: 2026-03-20  
Projet: `C:/Dev/Sub3D`

## 1. Objectif

Ce document sert a cadrer une commande a un freelance 3D pour le premier sous-marin proto.

But:

- gagner du temps
- eviter un mesh joli mais inutilisable
- acheter un livrable utile au gameplay

## 2. Ce Qu’Il Faut Acheter

Pour Proto 03, le meilleur achat n’est pas:

- un beau rendu spaceship
- un hero asset high poly seulement
- une piece uniquement exterieure

Le meilleur achat est:

- un **blockout propre interieur + exterieur**
- ou un **modele gameplay-ready simple**

## 3. Livrable Recommande

Commande ideale:

- coque exterieure simple
- shell interieur jouable
- helm console
- engine block
- pump console
- bulkhead door simple

Formats exiges:

- `FBX`
- fichier source (`.blend` ou `.max`)

## 4. Contraintes De Design

- petit sous-marin d’exploration
- equipage reduit
- civil / industriel independant
- non militaire
- non luxueux
- peu de fenetres, petites et renforcees
- circulation claire en third-person

## 5. Contraintes Gameplay

- interieur lisible
- 3 zones:
  - helm
  - corridor
  - engine/pump room
- murs lisibles pour futures breches
- pas d’encombrement central
- pas de design labyrinthique

## 6. Dimensions A Imposer

- longueur exterieure: `14.8m`
- largeur exterieure: `5.2m`
- hauteur exterieure: `4.8m`
- longueur interieure utile: `12.2m`
- largeur interieure utile max: `3.6m`
- hauteur interieure claire: `2.35m`
- couloir clair: `2.3m`
- portes: `1.2m x 2.1m`

## 7. Ce Qu’Il Ne Faut Pas Commander

- modele purement photorealiste
- spaceship concept libre
- asset tres detaille sans source file
- interieur non fourni
- design sans echelle precise
- topologie ultra dense pour rien

## 8. Milestones Recommandes

Milestone 1:

- blockout exterieur + interieur
- validation proportions et circulation

Milestone 2:

- passes de details simples
- stations principales

Milestone 3:

- export final FBX + source files


## 10. Evaluation Du Gig Montre

Le gig montre est probablement bon pour:

- spaceship hard surface
- rendu propre
- interpretation visuelle

Le gig montre n’est pas automatiquement bon pour:

- layout interieur jouable
- gameplay readability
- UE5 blockout discipline
- asset optimise pour iteration de prototype

Conclusion:

- bon candidat possible
- mauvais achat si tu commandes juste le package tel quel sans brief personnalise
