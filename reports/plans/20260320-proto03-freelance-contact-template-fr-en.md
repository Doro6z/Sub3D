# Sub3D Proto 03 - Freelance Contact Template FR EN

Date: 2026-03-20  
Projet: `C:/Dev/Sub3D`

## 1. Recommendation

The proposed approach is judicious.

Best structure:

- first contact
- short game pitch
- clear prototype need
- phase 1 blockout collaboration
- gameplay validation and iteration
- phase 2 game-ready asset production

This is better than ordering a final asset directly because it reduces:

- mismatch risk
- wasted detail work
- budget drift
- unusable interior/exterior design

## 2. French Contact Message

```text
Bonjour,

Je vous contacte pour un projet de jeu sous Unreal Engine 5.

Je cherche un freelance 3D capable de travailler non seulement sur un beau modele, mais surtout sur un asset utile au gameplay.

Le projet :
Il s’agit d’un jeu/prototype autour de sous-marins d’exploration dans un environnement hostile. Le ton est civil / industriel independant, pas militaire, avec des sous-marins qui servent a la fois d’outil, de lieu de vie et de machine de survie.

Mon besoin :
Je ne cherche pas a commander directement un asset final tres detaille. Je prefererais une collaboration en deux phases.

Phase 1 :
- blockout interieur + exterieur
- proportions et echelle credibles
- layout jouable et lisible
- validation dans Unreal pour mes tests gameplay

Une fois ce blockout teste, je ferai des essais en jeu et nous ajusterons ensemble les proportions ou certains volumes si necessaire.

Phase 2 :
- production de l’asset reel game-ready
- nettoyage / details utiles
- fichiers source + FBX

Je pense que cette methode est plus saine pour le projet, et bien entendu les prix seraient ajustes selon les deux phases et la charge reelle de travail.

Le premier sous-marin est un petit sub d’exploration, civil / industriel independant, avec interieur simple et lisible :
- helm
- corridor principal
- engine / pump room

Je peux fournir :
- brief visuel
- dimensions cibles
- references
- blockout plan / layout

Est-ce que ce type de collaboration progressive vous convient ?
Et seriez-vous a l’aise avec une premiere phase orientee blockout gameplay plutot que rendu final immediat ?

Merci.
```

## 3. English Contact Message

```text
Hello,

I am reaching out for an Unreal Engine 5 game project.

I am looking for a 3D freelancer who can work not only on a visually strong model, but more importantly on an asset that is useful for gameplay.

Project pitch:
This is a game/prototype built around exploration submarines traveling through a hostile environment. The tone is independent civilian / industrial, not military. These submarines are both machines, survival tools, and living spaces.

What I need:
I am not looking to order a fully detailed final asset right away. I would prefer a two-phase collaboration.

Phase 1:
- interior and exterior blockout
- believable proportions and scale
- readable gameplay layout
- validation inside Unreal for gameplay tests

Once that blockout is tested in-game, I will run gameplay checks and we can adjust proportions or volumes together if needed.

Phase 2:
- production of the real game-ready asset
- cleanup and useful detail work
- source files + FBX

I believe this is a healthier production method for the project, and of course pricing can be adjusted according to the two phases and the actual amount of work.

The first submarine is a small exploration vessel, independent civilian / industrial, with a simple readable interior:
- helm
- main corridor
- engine / pump room

I can provide:
- visual brief
- target dimensions
- references
- blockout plan / layout

Would this kind of progressive collaboration work for you?
And would you be comfortable starting with a gameplay-oriented blockout phase rather than jumping directly to a final polished render/model?

Thank you.
```
