Sub3D · HUD Icon Plate

Curated vocabulary for the crew HUD. Single-color stroke icons, 24×24 viewBox, 1.4 stroke, round caps and joins. Click any icon to copy its SVG. Pillar P11 of ui-pillars.md: every icon used in production must come from this plate or be added here first.

Context · interaction targets

Drive the dynamic icon at center-screen. Replace the abstract crosshair when an interactable is in focus. One icon = one verb. Consumed by P3 zone "Center" and P1 item-driven panels.

Posture · self body state

Used inside the bottom-right status panel as a stick figure. Pillar P4: posture is always visible. These icons embed in larger SVG silhouettes; this page shows the compact glyph form.

Vitals · self gauges

Bar-mounted icons for HP/Fatigue/XP (P2 — the only three bars). Other vitals (hydration, hunger, body temp) appear in the detail overlay only, never on the default HUD.

Status · per-limb / per-crew indicators

Used on crew roster dots and detail-overlay limb tags. Color carries severity; shape carries category.

Submarine · world / vessel info

P1: submarine info appears via item-driven panels (hull-checker, sonar pinger, helm console), not as a default panel. These icons label modular widgets when the requesting item is held.

Equipment · tools and wearables

Hotbar, held tool, backpack contents, equipment-driven panel headers. Each item that requests UI also has an icon here.

Alerts · escalation events

Bottom-right alert zone. Default tone is crimson; preview here in text tone for shape comparison.

Inventory · UI affordances

Slot decorations, drop / lock / equip glyphs, navigation cues. Used on hotbar slots and overlay surfaces.
